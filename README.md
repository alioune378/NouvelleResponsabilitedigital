# Nouvelle Responsabilité — prototype de plateforme numérique

Démonstration indépendante réalisée par **Dalal Technologies** (dalaltechnologies.com). Ce n'est pas le site officiel de Nouvelle Responsabilité.

- `index.html` — site public (FR / WO / EN), responsive mobile
- `admin.html` — démonstration de l'espace d'administration (données fictives)
- `img/` — photos optimisées (WebP) et logos

Site statique, sans build : Netlify publie le dossier racine (`netlify.toml`).
Toutes les données de démonstration restent dans le navigateur du visiteur (localStorage) ; rien n'est envoyé à un serveur.
Le site est exclu des moteurs de recherche (`noindex`, `robots.txt`).
